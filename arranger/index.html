NES Arranger

Give it a lead sheet or a MIDI song. A genetic algorithm evolves an arrangement for the four channels of the NES sound chip, and you hear it next to the original. Your file stays on this device.

You can also drop a MIDI or ABC file anywhere on this card. It stays on this device.

Run

Choose a song first.

Starts the random generator. The same song, seed and settings always give the same arrangement; another seed gives another plan.

Full speed finishes in about a second; watch runs about 400 generations per second, so you can follow the evolution. The arrangement is the same.

Settings

The defaults are the command line's (configs/default.json). A bold name differs from its default, shown below it. Hover or focus a field to read what it changes.

Evolution

The fitness curve and the plan of every bar appear here while the run evolves.

Result

Play the arrangement on the NES chip, compare it with the original, and download the MIDI, the settings and the lead sheet.

How it works

Same seed, same arrangement. The app has its own seeded random generator, so the same song, seed and settings give the same arrangement in any browser. The command line uses numpy's generator: the same seed there gives a different arrangement, equally valid. The algorithm, the settings and the fitness are the same, and tests check that both score a plan identically.

Your files stay here. A file you open or drop never leaves this device. To find catalog songs, the page asks the project's song server only for the song's identifier or your search words.
