Starts the random generator. The same song, seed and settings always give the same arrangement; another seed gives another plan.

Full speed runs as fast as your device can: 1 to 3 seconds for a 32-bar song on a computer, a few times that on a phone. Watch runs about 400 generations per second, so you can follow the evolution. The arrangement is the same.

Result

How it works

Same seed, same arrangement. The app has its own seeded random generator, so the same song, seed and settings give the same arrangement in any browser. The command line uses numpy's generator: the same seed there gives a different arrangement, equally valid. The algorithm, the settings and the fitness are the same, and tests check that both score a plan identically.

Your files stay here. A file you open or drop never leaves this device. When the project's song server is running, the page asks it only for a song's identifier or your search words.

Downloaded songs. A song you download and open here is remembered in this browser, so it needs downloading only once. Nothing is uploaded.
